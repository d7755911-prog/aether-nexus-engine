# 🤝 Contributing to AETHER-MIND Nexus Engine

Thank you for your interest in contributing to the AETHER-MIND Spatial Engine!

## 🚀 Development Workflow

1. **Fork the Repository:** Create your own feature branch (`git checkout -b feature/SpatialOptimization`).
2. **Commit Conventions:** Follow strict commit naming:
   - `feat:` New feature or engine capability
   - `fix:` Bug fixes in rendering/backend logic
   - `perf:` Latency or mesh rendering optimization
3. **Run Diagnostics:**
   - Ensure backend tests pass (`pytest`)
   - Ensure frontend builds without type errors (`npm run build`)
4. **Submit PR:** Target the `main` branch with a clear description of changes.

## ⚙️ Coding Standards
- **Python:** PEP 8 compliance, strict typing via `pydantic`.
- **Frontend:** TypeScript strict mode, functional Next.js components.
